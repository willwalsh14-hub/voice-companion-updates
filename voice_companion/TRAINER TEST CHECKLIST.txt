VOICE AND WEB REGRESSION CHECK: While mail speech is still talking, say "Voice list" and confirm the available voices are spoken. In a folder, say "Open message" and "Open that"; say "New message," "Start dictation," "Stop dictation," then "Go back" and confirm the same folder remains open. On a Google results page, say "List links," "Next links," and "Open link 1"; confirm the destination before saying "Yes."

LINK DETECTION: On a page with a delayed result and a link in an embedded frame, say "List links" and verify both results are announced. Confirm "Open link 1" still requires Yes and the link opens.

NATURAL EMAIL TEST: In a connected Gmail draft, say the recipient and subject, then speak a body without "Start dictation." Verify it saves. Say "Send it tomorrow" and verify those words remain in the draft. Say "Send that" and verify it reads sender, recipient, subject, body, and sends nothing. Say "Cancel send" and verify "Yes" does not send. Review again and say "Yes" only for a safe test address. Repeat with reply and forward.

INPUT MODES: Without saying start dictation, create a document and speak a sentence. Switch to Commands only; speak another sentence and verify it was not added. Switch to Dictation only; say "read document" and verify those words were added instead of invoking the command. Switch to Normal mode and verify Read document works. Repeat in a mail draft and focused ordinary web text field. Confirm password fields reject speech and dictation only cannot send.

READING AND VOICE PICKER: Open a message and verify it reads body first; "Message details" reads sender, subject, date. In document, draft, web page, note, and message, try next/previous character, word, line, sentence, paragraph, start reading, and continue reading. Preview next/previous voices, cancel to restore the old voice, then choose "That one" and verify it survives restart. After a successful new send, verify Inbox focus; after a reply, verify the original message. Do not repeat a real send to test uncertain delivery.

DICTATION CLEANUP: In a new email, say "Same here, Bob, period. Uh" and review the saved body. It should read "Same here, Bob." Confirm a separate "uh" adds nothing. "The period of history" must remain words, and "type literally uh period" must preserve both words. Do not send until the whole review is correct.

SEARCH VERIFICATION: Search the web and confirm results are read from Brave Search, with spoken links. Try an explicit Google search. On a human verification page (including an iframe), confirm Companion says verification is required rather than claiming there is no content, and that the fallback search is announced. If every engine is blocked, it must say so without claiming to have results.

DOCUMENT FORMATTING CHECK: Create a document and try heading level two, bold, italic, underline, font and size, bulleted and numbered lists, and a two-by-two table. Fill and navigate cells, add a row and column, save, close, reopen, and verify the Word file and spoken table review. Try Undo after deleting a table. Test on a real Windows build before client use.

LINE SPACING CHECK: Dictate two paragraphs. Say line spacing 1.75 on one and line spacing exactly 18 points on the other. Save, reopen, and hear each value with read line spacing. Say set document line spacing to 1.25, verify both changed, then undo.

SHORT SPACING PHRASES: Test single space, double space, custom spacing, a valid spoken number, an invalid number followed by a correction, and cancel. Confirm the value is not dictated into the paragraph and still reads correctly after reopening.

CUSTOM SPACING CONFIRMATION: Start custom spacing, speak a value, and verify the DOCX has not changed. Say change it, speak another value, then confirm that; verify the second value is saved. Repeat with cancel and verify no change. Test this in the normal window with a Windows voice, since confirm that also confirms voice choices when the voice picker is open.
