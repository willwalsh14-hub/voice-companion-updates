VOICE COMPANION - TEST CHECKLIST

Use this on the Windows computer that the person will use. A build check cannot test their own voice, microphone, hearing, or account.
Use spare files, mail, and web forms. Write PASS, FAIL, or NOT TESTED beside each check. Record the exact words or error message when a check fails.

1. Install and start
___ Install VoiceCompanion-Setup.exe.
___ Open the desktop icon. Check that the app window opens and speaks.
___ Say "What version?" and compare it with the release you installed.
___ Run check-setup.cmd from the installed app folder. Check that its tests pass.
___ Turn off your screen reader for the app's speech test. Press Y only if you hear Companion's own test sentence.
___ Run test-microphone.cmd. Say "Wake up. Create a document." Check its result and the words it heard.
___ Start the app normally. Say "Wake up", then "Create a document".
Result: ____________________

2. Microphone and speech
___ Repeat with the microphone and speaker or headset the person plans to use.
___ While text is read, say "Be quiet". Check that speech pauses with no reply.
___ Say "Keep going". Check that reading continues.
___ Press Control during speech. Check that it stops.
___ Give a new command during speech. Check that the old message stops.
___ Try "Faster", "Slower", and "Punctuation all".
___ Choose a voice with "List voices", "Next", and "Okay". Cancel a choice and check that the earlier voice returns.
___ Try the US and UK English eSpeak voices. Reopen the app and check the saved voice and speed.

3. Help and lessons
___ From a document, say "Help with documents". Open a part and read it.
___ Move to another part while Help is speaking. Check that the old speech stops.
___ Say "Close help". Check that you return to the same document.
___ Repeat from email, the web, radio, podcasts, and the main menu.
___ Use arrows, Enter, and Escape in Help. Check that headings and choices are clear.
___ Say "Start tutorial". Try Next lesson, Repeat, Lesson list, and Explain command.

4. Write and save
___ Create and name a test document. Speak two sentences without Start dictation.
___ Use Commands only. Speak another sentence and check that it was not added.
___ Use Dictation only. Say "Read document" and check that those words become text.
___ Use Normal mode. Check that "Read document" now reads the text.
___ Open Input options. Set Dictation type to AI-based and save. Restart and check that the choice is kept.
___ In a document, note, email body, and web text box, say "I I, um, want to go." Check the text. Try a short pause and a long pause. Note the time until the text appears.
___ Say "Very, very good" and "I had had enough." Check that these words are kept. Try "Type literally I I um". Use Undo in the document.
___ Check that passwords, email addresses, and typed text are not cleaned. Set Old school and check that the prior speech entry still works. Cancel an Input options change and check that it is not saved.
___ Save, close, reopen, and check the name and text.
___ Try Save as with a new name. Check both copies.
___ Try a rename, then Undo. Check the old name returns.
___ Leave a document and answer No at the save question. Check what was kept.
___ Write a note. Go back, reopen it, and check the text.

16. Report a problem
Record the app version, Windows version, microphone, speaker or headset, step, site or service, and exact message.
Say what you expected and what happened. Mark any missed tests as NOT TESTED.
Keep a failed test result for the person fixing the app. Do not send them passwords, private keys, or personal mail.
Check all tasks the person needs before relying on the app for important work.

Dictation and keyboard checks
Choose each Dictation type in Input options, save, and restart. Dictate I I um will call in text and mail. AI-based should trim the clear false start; Old school should keep it.
In Verbosity, try all three Echo dictated text choices. Check the short pause and no Added label. In sentence mode, pause mid-sentence, then finish it. Check quiet mode.
Dictate in a text file, mail, and a web field. Use arrows, Home, End, Shift plus arrows, and type a change. Keep all new text. Repeat with fast typing just before speech ends.

Book Services regression
Open fullcircleat.com, then Book Services. Find a service radio button with the virtual cursor. Press Space, then test Enter on another service. Check that one service stays selected and the dates load. Check a date with available times. Do not submit a booking during this check.
Set Echo dictated text to at the end of a sentence. Say I will call, pause, then you tomorrow, pause, then period. The full sentence should be read once. Check stop speech and a change of document clear old text.

Options close and return
Open Options from a document, mail, web page, and note. Open a category. Check the name is followed by dialog. Change a choice or checkbox and press Enter. Check Options saved is spoken once, the window closes, and focus returns to the same task and place. Reopen Options and check the value was saved. Check Cancel still discards changes. Web browser options must not list website favorites. Favorites remain in the browser menu.

File manager and reader
Check File manager is first on the main menu. Enter should list the local drive, any attached drives, mapped drives, registered cloud roots, and the standard folders. Use a disposable folder only for file action tests.
Enter nested folders and press Escape once per level. The parent folder and previous item must be retained. Home and End must stop at list boundaries.
Mark several files with Space and each selection voice alias. Copy, cut, and paste between disposable folders. Check both clipboard directions with File Explorer. A cut must leave the source until paste succeeds. Duplicate names must not be overwritten. Rename one item and confirm deletion of a disposable copy only. Check it reaches Recycle Bin. No is the first delete choice.
Press Alt and review every command, shortcut, and voice phrase. Check Ctrl A, Ctrl Shift A, F2, Delete, Ctrl C, Ctrl X, Ctrl V, F5, Ctrl Home, and Ctrl M. Type a rename with extension. Cancel it once before completing it.
Open DOCX, Unicode TXT, HTML, PDF, ODT, and EPUB samples. Read with arrows and voice. Escape must return to the same folder and item. The source file must stay unchanged. Check scanned and password-protected PDFs give clear limits.
Open Options from a document, email, web page, file list, and reader. Each category says its full options name and dialog. Saving announces Options saved and the returned task.
