VOICE COMPANION - START HERE

1. About the app
Voice Companion is a test app for Windows. It speaks its own menus and messages. You can use your voice, the keyboard, or both.
It can write documents and notes, use email, browse the web, and play radio and podcasts. Microsoft Word is not needed to write a document.

2. Install and start
1. Open VoiceCompanion-Setup.exe.
2. Follow the setup prompts.
3. On the last page, leave Open Voice Companion now checked.
4. Choose Finish.
You can open the app later from the desktop icon or the Windows Start menu. You do not need to install Python or build the app.
Wait for the ready message, then say "Wake up". Choose a tool by name. You can also use arrows and Enter.

3. Read the full guide
Say "Open user guides". The folder opens in Windows.
Open START HERE - Veteran in the format you prefer. The title inside is Voice Companion User Guide.
The guide has 22 chapters with short steps. It covers voice commands, keys, settings, and help with problems.
The text, HTML, Word, EPUB, DAISY, and braille copies have the same steps. Release notes in the folder explain the latest changes.
Say "Help with documents", "Help with email", or "Help with web" to hear a topic in the app. Say "Close help" to return to your work.
Say "Start tutorial" for spoken lessons. The lessons leave your real work alone.

4. Check an update
Say "Check for updates". If an update is offered, say "Yes" to install it or "No" to keep working.
The app saves your work, downloads the update, closes, and opens again after setup. Windows may ask for help with a security prompt.
After an update, close and reopen a guide to see its new text.

5. Before you rely on it
This is still a test app. Check important text and actions. Speech can hear the wrong words.
Email needs an account connection. Test sending with someone you know before relying on it. Read the whole review before you say "Yes".
Some web pages and audio streams may not work. See chapter 22 of the guide for help.

6. If you are building the app
These source files are also used to make the installer. Build instructions are in BUILD ON WINDOWS - READ ME.txt.
People using the app should receive the checked installer. They do not need the source files or build tools.
