Guide version: 0.2.127-test.

Use this guide to learn Voice Companion, change its settings, and find help. Voice Companion speaks its own menus and messages. You can use your voice, your keyboard, or both. You do not need Microsoft Word or a screen reader to use its tools.

This is a test version. Some websites, email services, and audio streams may not work as expected. Read each message before you send, delete, or change anything important.

1. Getting Started

1.1 Install Voice Companion

Use the file named VoiceCompanion-Setup.exe. This is the installer. It puts the app and its guides on your computer.

  1. Open the installer.
  2. Follow its prompts.
  3. On the last page, leave Open Voice Companion now checked if you want to start the app.
  4. Choose Finish.

You can open the app later from its desktop icon or the Windows Start menu. Use the installed app, not an older copy from a download folder.

1.2 Open the app and wake it

  1. Open Voice Companion.
  2. Wait while it checks for updates.
  3. If it offers an update, say "Yes" or "No". You can also use the arrow keys and Enter.
  4. When it says it is ready, say "Wake up".
  5. Wait for the main menu. Say the name of the tool you want.

For example, say "Word processor", "Notepad", "Email", "Web browser", "Radio", or "Podcasts".

The keyboard works while the microphone is asleep. Press Down Arrow to hear a menu item. Press Enter to open it.

Say "What version?" to hear the version you are using.

1.3 Use the main menu

The main menu has these choices:

  • Word processor
  • Notepad
  • Email
  • Web browser
  • Radio
  • Podcasts
  • Options
  • Check for updates
  • Help
  • Shut down the computer
  • Restart the computer
  • Exit Voice Companion

Voice: Say "Next" or "Previous" to move. Say "That one", "Okay", or "Confirm" to open the item you hear.

Keyboard: Use Up Arrow and Down Arrow to move. Press Enter to open an item. Home selects the first item. End selects the last item.

You hear "Start of list" or "End of list" if you try to move past an end. The list does not wrap around.

In most menus, press the first letter of a name to find a matching item. Press Enter to open it. Text boxes use those keys for typing instead.

1.4 Set up your microphone

Voice Companion uses the microphone selected in Windows. A built-in microphone or a working headset can be used.

A headset helps keep the app's speech out of the microphone. It can also make your own voice easier to hear.

If voice commands do not work, check the microphone in Windows sound settings. Check that apps can use it. Then close and reopen Companion.

You can keep using the keyboard if the microphone is not available.

2. Using Voice Commands

2.1 Give a command

Say a command, then wait for the reply. For example, say "Help" to open the guide.

In a menu, say "Next", then "That one" to choose the item you hear. Say "Main menu" to return to the start.

Names in examples are sample names. Replace them with your own document, contact, folder, or bookmark name.

2.2 Speak text or give commands

Normal mode lets you give commands and speak text. In a document, draft, note, or web text box, ordinary speech adds text.

Say "Commands only" when you want to move around without adding text by mistake.

Say "Dictation only" when you want your speech to become text. In this mode, some words that are usually commands become text.

Say "Normal mode" to return to voice commands and text entry. Say "What mode?" to hear the current choice.

You can still leave a document, cancel a draft, or put Companion to sleep in dictation-only mode. Some editing commands also remain available.

When you are unsure, use Normal mode before giving an editing or reading command.

2.3 Enter words that sound like commands

Say "Type literally" before words you want to write exactly. For example, "Type literally new line" writes the words new line.

Without that prefix, "New line" makes a line break. "New paragraph" starts a new paragraph.

Say punctuation names while you speak. For example, "Hello comma Sam period" writes Hello, Sam.

Listen to the result. Speech recognition can choose the wrong word or punctuation mark.

Typed words are taken as text. Typing period does not make a period mark.

2.4 Type a voice command

  1. Press Alt+T to reach the command box.
  2. Type the command. For example, type list documents.
  3. Press Enter.

Use this path when you prefer the keyboard or a voice command is not heard correctly.

In a web page, Alt+T lets you type an app command. Press Escape to return to page reading.

2.5 Answer Yes or No

When Companion asks a question, listen to the item name and the action first.

Say "Yes" to do the action. Say "No" or "Cancel" to stop it.

Keyboard: Use arrows or Tab to choose Yes or No, then press Enter. Alt+Y answers Yes. Alt+N answers No. Escape cancels.

At a Yes or No prompt, Home selects Yes and End selects No.

3. Using Help And Lessons

3.1 Open a Help topic

Say "Help" to open the guide inside the app. Use "Next", "Previous", and "That one" to choose a topic.

You can go straight to a topic. For example, say "Help with documents", "Help with email", or "Help with web".

Other useful requests are "Help with radio", "Help with podcasts", "Help with presets", and "Help with commands".

Keyboard: Use the arrows and Enter to choose. Home and End reach the ends of a list.

3.2 Read part of a topic

A large topic has a list of smaller parts. Choose the part you want, then listen.

Say "Continue reading" for more. Say "Read from top" to start that part again.

Say "Next paragraph", "Previous paragraph", "Next sentence", or "Next word" to move through the text.

Choosing another Help item stops the old speech before the next item is read.

Press Control to silence speech. Say "Back to subsections" to return to the smaller parts.

Say "Back to topics" for the full topic list. Say "Close help" to return to your work.

3.3 Start the audio tutorial

The tutorial explains how to use the app. It waits for you between lessons. Commands given there are explained; they do not send mail or change your files.

  1. Return to the main menu.
  2. Say "Start tutorial".
  3. Say a course name, such as "Email" or "Web browser". You can also use arrows and Enter.
  4. Listen to the first lesson.
  5. Say "Next lesson" when you are ready.

Courses cover Getting started, Word processor, Notepad, Email, Web browser, Radio, Podcasts, Options, and Help and updates.

3.4 Find, repeat, and leave a lesson

Say "Repeat" to hear the same lesson. Say "Previous lesson" to go back.

Say "Lesson list" for the lesson names. Use arrows and Enter to choose one.

Say "Find lesson" followed by a topic. For example, say "Find lesson bookmarks".

Say "List commands" for the course's command list. Say "Explain command send it" to hear how that command works.

Long explanations may need "Continue reading". Say "Courses" to return to the course list.

Escape goes back one level. Say "Main menu" or "Close tutorial" to leave the tutorial.

4. Speech And Voices

4.1 Stop or pause speech

Press Control to silence Companion. This works while the microphone is asleep too.

By voice, say "Be quiet", "Stop talking", "Pause", or "Shut up". Say "Resume" or "Keep talking" to continue paused speech.

A new command can stop the old reading and do something else. For example, say "Next message" while mail is being read.

For audio such as radio or podcasts, use "Pause audio" or "Stop audio" to make your meaning clear.

4.2 Change speed, volume, or pitch

Say "Faster" or "Slower" to change speech speed. Say "Louder", "Quieter", or "Softer" to change volume.

For a set value, say "Rate four", "Speed four", or "Volume fifty".

Speech rate runs from minus ten to ten. Zero is the normal speed. Volume runs from zero to one hundred.

Pitch changes how high or low a voice sounds. Say "Higher pitch", "Lower pitch", or "Pitch minus three".

Pitch runs from minus ten to ten. These settings are separate from text size or music volume.

Keyboard: Press Alt+O. Open Voice options. Use Tab to reach a setting, then use arrows to change it. Choose OK to save.

4.3 Choose a voice

  1. Say "Voice list" or "List voices".
  2. Choose the speech system you want. The list calls this a synthesizer.
  3. Choose a voice from that system.
  4. Listen to the sample and confirm your choice.

SAPI means the voices provided by Windows. eSpeak has US and UK English choices. AI voices need a separate setup and an internet connection.

Use "Next voice", "Previous voice", and "Okay" to choose. Say "Cancel voice" to keep your earlier choice.

The available voices depend on what is installed and set up on your computer.

4.4 Use an AI voice

An AI voice reads some app text through an online service. Your helper must set up access before you can use it.

Open Options, then Synthesizer options. Your helper can enter the service key in the private AI API key box. This key is a code that gives the app access to the speech service.

Choose whether to allow the text being read to be sent to OpenAI. Save the setting only when you agree.

Say "Use AI voice" after setup. Say "Use SAPI" or "Use eSpeak" to use local speech instead.

An AI voice needs internet access and may use paid service credit. Long reading may take longer to start.

Typing and quick movement feedback use a local voice so each key can be heard promptly. If online speech fails, Companion uses local speech.

5. Reading And Editing Text

5.1 Read from your current place

These commands work in documents, email, web pages, and notes where text reading is available.

Say "Read from top" or "Start reading" to start at the beginning. Say "Continue reading" for the next part.

Say "Next character" or "Previous character" to move by letter or symbol.

Say "Next word" or "Previous word" to move by word.

Say "Next line" or "Previous line" to move by line.

Say "Next sentence" or "Previous sentence" to move by sentence.

Say "Next paragraph" or "Previous paragraph" to move by paragraph.

A line here may follow a line break in the text. It may not match a line shown on the screen.

5.2 Read with the keyboard

Left Arrow and Right Arrow move by character. Control+Left Arrow and Control+Right Arrow move by word.

Up Arrow and Down Arrow move by line. Control+Up Arrow and Control+Down Arrow move by paragraph.

Home and End reach the start or end of a line. Control+Home and Control+End reach the start or end of the text.

In web pages, Page Up and Page Down move a longer distance. Page reading starts from the place you last chose.

The same keys can review a received email. You can read and copy received text, but you cannot rewrite that message.

5.3 Select text

Selected text is the part you have chosen to copy, change, or delete.

Keyboard: Hold Shift with a movement key. Control+A selects all the text in an open text view.

Voice: Say "Select word", "Select line", "Select sentence", "Select character", or "Select paragraph" for the current part.

Say "Select all" for all the text. Say "What is selected" or "Read selection" to check your choice.

In a document or draft, say "Select first paragraph", "Select next paragraph", "Select previous paragraph", or "Select paragraph 3".

You can use first, next, previous, last, current, or a number with character, word, line, sentence, and paragraph.

In email address and subject boxes, a note, or a web text box, selection applies to that box's text.

Web page reading text is read-only. To change a web answer, enter its text box first.

5.4 Choose named words

Say "Select red fox" to choose those words. Say "Select red fox through sleeps" to choose a longer passage.

You can also say "Selection start at cat", then "Selection end at dog".

If the words appear more than once, Companion reads each matching place. Say "Next" or "Previous" to hear another match.

Say "Read sentence" to hear the nearby sentence again. Say "That one", "Confirm that", or "Okay" to choose.

Say "First match", "Second match", or "Match 3" to choose by number. Say "Cancel selection" to leave the text as it is.

To select the word all rather than all the text, say "Select the word all".

5.5 Copy, cut, paste, or remove text

Say "Copy selection", "Cut selection", or "Paste". Keyboard: use Control+C, Control+X, or Control+V.

In a document or draft, you can also name the words. For example, say "Copy cat", "Cut cat", or "Delete cat".

Say "Delete word", "Delete line", "Delete sentence", or "Delete paragraph" to remove the current part.

Say "Scratch" or "Scratch that" to remove selected text. With no selection, it removes the most recent spoken addition where supported.

In documents and draft message bodies, say "Undo" to reverse an edit. Check the text after the change.

Moving to a new place clears the old selection. Check your choice again before you change or remove text.

5.6 Replace or insert words

Say "Replace cat with dog" or "Change cat to dog" to find and change the words.

One match is changed at once. With several matches, use "Next", "Previous", and "That one" to choose the right place.

Say "Cancel replacement" to stop without changing the words. Say a punctuation name if you want it in the new text.

For example, "Replace cat with dog period" includes a period. A period added to the end of a recognized command is not treated as your new text.

Say "Replace word with hello", "Replace sentence with Thank you", or "Replace paragraph with I will call tomorrow".

Say "Insert before red fox" or "Insert after red fox" to choose where to add text.

Choose a matching place if asked. Then speak the words to add. In Commands only, use "Type literally" before the new words.

6. Write A Document

6.1 Create and name a document

The Word processor makes files that Microsoft Word can open. Word does not need to be installed.

  1. Say "Create a document" or choose Word processor.
  2. Say "Name document My Letter" to name the file.
  3. Speak a short sentence or type into the document.
  4. Say "Read paragraph" to check what you wrote.

The file name and the title inside your letter are separate. Naming the file does not add a title to the page.

You can also press F2 to reach the name box. Say the name, then say "Okay", or type the name and press Enter.

6.2 Write and move through the document

Say "New paragraph" to start a new paragraph. Say "New line" to start a line in the same paragraph.

Say "Read paragraph", "Spell word", "Next word", or "Next sentence" to review your text.

Say "Go to beginning of document" or "Go to end of document" to move to an end.

"Move to beginning of document", "Move to end of document", and the matching jump commands also work.

After moving, new words are added at that place. A previous selection is cleared.

You can type directly too. Enter creates a paragraph. Use the reading and editing keys in chapter 5.

6.3 Change the look of text

Choose the text first if you want to change only part of it. With no selection, many commands change the current paragraph.

Say "Make this bold", "Make this italic", or "Underline this". Say "Remove bold", "Remove italic", or "Remove underline" to turn a style off.

To change named words, say "Bold cat", "Italicize cat", "Underline cat", or "Highlight cat".

Say "Set font to Arial" to choose the letter style. Say "Set font size to 14 points" or "Set size 14" to choose its size.

You can set both at once. For example, say "Set font Times New Roman 16 point".

To change just the current word, say "Bold word", "Italic word", "Underline word", or "Set word size to 14 points".

Say "Set word font to Arial" to change that word's font. "Remove bold from word" turns bold off for that word.

Say "Say font" or "Read formatting" to hear the text settings. "Say font name", "Say size", "Say bold", "Say italic", and "Say underline" read one setting.

If selected text has more than one setting, Companion tells you that the setting is mixed.

6.4 Use headings and align text

A heading names a part of your document. Heading levels run from 1 to 6.

Say "Heading 1" or "Apply heading 1" for a main heading. Use another number for a smaller heading.

"Make this a heading" uses level 1. "Normal text" removes the heading style.

Say "Align left", "Align center", "Align right", or "Align justified" to place a paragraph on the page.

Justified text lines up with both page edges. Say "Say alignment" or "Say heading" to check the setting.

With selected text, these commands apply to the selected paragraphs.

6.5 Change line spacing

Line spacing is the space between the lines in a paragraph.

Say "Single space", "Double space", or "Line spacing 1.5" to set it.

For another value, say "Custom spacing". Give the value when asked, such as "One point seven five" or "Exactly eighteen points".

Companion repeats the value. Say "Yes" to use it, "No" to give another value, or "Cancel" to stop.

Say "Set document line spacing to 1.25" to change the whole document.

Say "Read line spacing" for the current paragraph. Say "Read document line spacing" for the whole document.

"Reset line spacing" resets the current paragraph. "Reset document line spacing" resets all paragraphs.

A new paragraph keeps the spacing of the paragraph before it.

6.6 Make a list

  1. Say "Bulleted list" or "Numbered list".
  2. Speak or type the first item.
  3. Say "New paragraph" for the next item.
  4. Say "End list" when you want to return to ordinary text.

A bulleted list marks each item with a dot. A numbered list gives each item a number.

6.7 Make a table

  1. Say "Create table with two rows and two columns".
  2. Speak the text for the first cell. A cell is one box in the table.
  3. Say "Next cell" to move to the next box.
  4. Say "Read table" to check your work.

You can also use "Previous cell", "Next row", "Previous row", "Next column", and "Previous column".

Say "Read cell" to hear the current cell. "Clear cell" removes its words.

"Add row" and "Add column" make the table larger. "Delete row" and "Delete column" remove those parts.

Say "Leave table" to write after the table. "Delete table" removes the table. Say "Undo" at once if that was a mistake.

The editor makes simple tables with straight rows and columns. It may not open more complex tables from other programs.

6.8 Save, copy, close, or reopen a document

Companion saves as you write. Say "Save document" to save under the current name.

Say "Save as My Letter Copy" or "Save document as My Letter Copy" to keep a second file. The first file stays in place.

"Name document My Letter" changes the file name. "Undo" right after a rename restores the earlier name.

Say "Leave document", "Exit document", or "Go back" when you are done. Companion asks whether to save.

Yes keeps the current name if the file is already named. An untitled file needs a name. No discards changes since you last opened, saved, or named the file.

Press Escape at the save or name prompt to keep editing. Check the file name Companion reads before leaving.

Say "Resume document" to return to the current document while Companion remains open.

After reopening the app, say "List documents", then choose a file. "Open document My Letter" opens a named file.

Say "Open documents" to open the document folder in Windows. "Where are my documents?" reads its location.

Files are kept in Documents, inside the Voice Companion folder. They use the .docx file type.

Companion can reopen the simple files it creates. It may refuse a complex Word file to avoid changing it incorrectly.

7. Write A Note

7.1 Start and save a note

Notepad is for a short plain text note. Use the Word processor when you need headings, fonts, or tables.

  1. Say "Write a note" or choose Notepad.
  2. Speak your note.
  3. Say "Read from top" to listen to it.
  4. Say "Save note" to save it.

Say "Go back" to save the current note and return to the main menu. Going to sleep also saves the words already heard.

7.2 Review or change a note

Use "Next word", "Previous word", "Next line", and "Previous line" to review.

Use "Next sentence", "Previous sentence", "Next paragraph", and "Previous paragraph" to move through longer text.

"Select all", "Select word", and "Select paragraph" choose text. "Read selection" checks it. "Scratch" removes selected text.

"Next character" and "Previous character" help you check a spelling. "New line" and "New paragraph" add breaks.

Use "Commands only" to review without adding speech as text. Say "Normal mode" when you want to write again.

To write the words new line, say "Type literally new line".

The same selection and editing rules apply to the current note. Keep a saved copy of any note you need.

8. Set Up Email

8.1 Connect an email account

Connect an account before relying on Companion to send or organize email.

  1. Say "Add account".
  2. Choose Gmail, Outlook or Exchange, or Yahoo.
  3. Follow the sign-in prompts. Ask your helper if you need help with the sign-in page.
  4. Open the inbox and test a message with someone you know.

Google and Microsoft use their usual sign-in pages. Work or school accounts may need your organization's approval.

Yahoo needs an app password. This is a password made in Yahoo's account settings for an email app.

Enter passwords and codes privately. Do not read them aloud to someone you do not trust.

If account setup is not available, ask your helper to check the app's email setup.

8.2 Choose another account

Say "Add another account" to connect a second address. Say "List email accounts" to hear the saved accounts.

Say "Switch to Yahoo" or "Switch to Outlook" if only one account of that type is connected.

With two accounts of the same type, say "Switch to" followed by the full address.

Say "Which email account?" to hear the account in use. Check it before sending mail.

"Check Gmail", "Check Outlook", and "Check Yahoo" open that account when exactly one of its type is connected.

8.3 Add and find contacts

A contact is a saved name and email address.

Say "Add contact Bob as bob@example.com" to save one. Say "List contacts" to hear names.

Say "Find contact Bob" to look for a name. Use the saved contact's name when Companion asks who to email.

Each email account has its own contact list. Local contacts can be used without internet access.

With Gmail selected, "Connect Google Contacts" or "Sync Google Contacts" asks for access to Google Contacts.

Approve that access only if you want to link those contacts. A helper can assist with the permission page.

Google Calendar and Google Drive are not connected in this version.

9. Write An Email

9.1 Start a new message

  1. Say "Write an email" from the main menu, or "New message" while reading email.
  2. Give the address or a saved contact name when asked.
  3. Give the subject when asked.
  4. Speak the message in short parts. Listen back before sending.

Keyboard: In email, Control+N starts a new message. Type an address in To and press Enter. Continue through the subject and message.

You can say an address using at and dot. For example, "sam at example dot com" means sam@example.com.

9.2 Change To, CC, BCC, or Subject

To names the person getting the message. CC sends a copy. BCC sends a copy without showing that address to the other people.

Say "Go to To", "Go to CC", "Go to BCC", "Go to Subject", or "Go to Body" to reach a part of the draft.

Type the address or subject and press Enter. Left Arrow and Right Arrow review characters. Backspace and Delete remove characters.

Say "Email to sam@example.com" to set To. Say "Subject is Hello from me" to set the subject.

Say "CC" or "BCC" to add a copy address. Say "Skip" if you do not want to add one.

"Read recipient", "Read subject", "Read CC", and "Read BCC" let you check those parts.

Tab moves to the next draft field. Shift+Tab moves to the previous field.

9.3 Write and format the message

Ordinary speech adds text to the message. "New paragraph" starts a paragraph. "Read paragraph" reads it back.

The text selection and formatting commands in chapters 5 and 6 work in the message body too.

You can change a font, text size, line spacing, heading, list, or table. Address and subject boxes use plain text.

The person reading your mail may see different fonts or spacing in their email app.

Use "Type literally" to write words that might be heard as commands. Use "Undo" to reverse an edit in the body.

9.4 Save or cancel a draft

Say "Save draft" to keep a message for later. Say "List email drafts" to find saved drafts.

Say "Open email draft Untitled", or use the draft name you heard, to reopen one.

Say "Cancel", "Cancel draft", "Go back", or "Back to inbox" to leave an unsent draft and discard its changes.

These cancel commands work in a new message, reply, reply-all message, or forward. They work from each draft field.

Save the draft first if you want to keep it. "Leave email" saves the draft and returns to the main menu.

Canceling cannot take back a message already sent. If you reopened a saved draft, canceling keeps its earlier saved copy.

9.5 Review and send

  1. Say "Send email", "Send it", or "Send that". Keyboard: press Control+Enter in the draft.
  2. Listen to the sending account, addresses, subject, and message.
  3. If something is wrong, say "Cancel send". Fix it, then start the review again.
  4. Say "Yes" only when the review is right.

Nothing is sent before the review and confirmation. If no account is connected, Companion saves a draft instead of sending it.

After the email service accepts the message, Companion says it was sent. Check delivery with your helper during early tests.

If it says the result is uncertain, check your mail account and ask the person before trying again.

10. Read And Organize Email

10.1 Read messages

  1. Say "Email" or "Check email" to open the chosen inbox.
  2. Listen to the sender, subject, and date of the selected message.
  3. Say "Next message" or "Previous message" to hear another summary.
  4. Say "That one" or "Open current message" to read its body.

You can also say "Read message 1" or "Open message 1" to choose by number.

Say "Message details" to repeat the sender, subject, and date. Say "Continue reading" for more of a long message.

Say "Read from beginning" to read it again. "Back to folder" or "Go back" returns to the message list.

Keyboard: Up Arrow and Down Arrow choose a message. Enter opens it. Escape returns to the list.

10.2 Go to folders

Say "Go to folder" to hear a folder list. Use "Next", "Previous", and "That one" to choose.

You can also say "Go to folder Receipts", "Open folder Receipts", or "Go to Receipts".

Use "Back to inbox" to return to Inbox. "Which folder" tells you where you are.

For a folder within another folder, try "Go to Projects slash 2026" or "2026 inside of Projects".

If two folders have the same name, listen to each full location. Choose the right one with "Next" and "That one".

Keyboard: Control+Y opens folders. Use arrows and Enter. Escape cancels the folder list.

10.3 Select, move, or delete messages

Say "Mark", "Select", "Mark message", or "Select message" to mark the message you hear.

Move to another summary and mark it too. "What is selected" reads the total. "Clear selection" removes the marks.

Say "Delete" to move marked messages to Trash. With no marks, it acts on the current message.

Say "Move" to choose a destination folder. "Move to Saved" uses a named folder.

"Delete message" and "Move message" act on the current message even if other messages are marked.

Listen to the action and names, then answer Yes or No. Check the folder before repeating an action with an uncertain result.

Keyboard: Space marks or unmarks a message. Shift+Up Arrow and Shift+Down Arrow extend the selection.

Control+A marks messages on the loaded page. Delete requests deletion. Control+Shift+V chooses a folder for moving mail.

Inside an open message, Control+A selects text to copy; it does not mark other messages.

10.4 Reply or forward

Open the message first. Say "Reply", "Reply all", or "Forward".

Keyboard: Control+R replies. Control+Shift+R replies to all. Control+F forwards.

Reply all includes the other people listed on the message. Check the addresses before sending.

For a forward, enter the new address when asked. Speak your added text, then use the review and send steps in chapter 9.

Gmail and Yahoo forwarding do not include the original attachments in this version.

Say "Cancel" or "Back to inbox" to discard the response draft. Say "Save draft" first if you want to keep it.

10.5 Create and manage folders

Say "Create folder Receipts" to make a folder. "Create folder 2026 inside Receipts" makes a folder within it.

"Create folder 2026 inside" opens a parent-folder list so you can choose where it belongs.

Say "Rename folder" to choose a folder, then say "Rename to Bills". You can also say "Rename folder Receipts to Bills".

"Move folder" asks for a folder and its new location. "Move folder Bills into Archive" gives both names.

"Delete folder" opens a folder list. "Delete folder Bills" names it directly.

Listen to the full folder location and the action. Say "Yes" to go ahead or "No" to cancel.

Only empty folders you made, with no folders inside them, can be deleted. Built-in folders such as Inbox are protected.

Some email services restrict folder changes. For example, Gmail labels with child labels have limits on renaming, moving, or deleting.

Keyboard: Control+Shift+E starts folder creation. F2 starts renaming. Control+Shift+D starts folder deletion.

10.6 Read links and load more mail

In email that keeps web-style formatting, links and buttons can be read with the message.

K moves to the next link. B moves to the next button. Hold Shift to move backward. Tab moves through both.

Press Enter to open a safe link. A button with no usable link is read but cannot run a script from the email.

Voice choices include "Next link", "Previous link", "Next button", "Previous button", "List links", and "List buttons".

Say "Activate current link", "Activate current button", "Open link 1", or "Open button 1" to use a listed item.

Say "Next messages" or "Previous messages" for another page of mail. "List messages" or F5 refreshes the folder.

Home and End reach the first and last messages in the folder. Messages from another page may need to load first.

Messages per list is in Email options. Choices include 10, 20, 30, 40, 50, 100, 1000, and all.

11. Browse The Web

11.1 Open the web browser menu

Choose Web browser on the main menu. It opens a web browser menu, even if you used a page earlier.

The web browser menu has these choices:

  • Search or type address
  • Go to bookmark
  • New bookmark
  • Delete bookmark
  • Rename bookmark
  • Go back
  • Go forward
  • Web history

When Keep browser window open is on and a page remains open, Resume where you left off is also shown.

Use arrows and Enter, or say the menu name. Escape from this menu returns to the main menu.

11.2 Search or open an address

  1. Choose Search or type address.
  2. Say your search, or type it and press Enter. For example, type weather in Houston.
  3. Wait for the page title and site name.
  4. Use the page reading commands to explore the result.

For an address, you can type example.com. You do not need to type www or https.

Voice: Say an address with dot or slash as needed. "Open website example dot com" asks you to check the address before it opens.

Control+L opens the address and search box from a page. Escape cancels entry.

Google is the default search engine. Options also offers Bing, Brave Search, and DuckDuckGo.

You can say "Search engine Brave Search" or "Default search engine Google" to change the default.

An explicit request such as "Bing weather" uses that engine for the current search.

If a site asks you to prove you are human, Companion cannot solve that check. It may offer another search engine.

Say "Try Brave Search", "Try Bing", or "Try DuckDuckGo" to repeat the search there. Your default stays the same.

11.3 Read a page

Companion reads the page in its own window. Use its page view for the keys below.

Up Arrow and Down Arrow read lines, including text between links. Left Arrow and Right Arrow read characters.

Control+Left Arrow and Control+Right Arrow read words. Control+Up Arrow and Control+Down Arrow read paragraphs.

Control+Home and Control+End reach the page ends. Home and End reach the ends of the current line.

"Read page" starts at the top. "Continue reading" reads the next part.

The page view follows the place you choose. After you move to a heading, arrow reading continues from that heading.

A newly loaded page may start reading on its own. Turn off Automatic page reading in Web browser options if you prefer.

11.4 Move to headings, links, or controls

H moves to the next heading. Shift+H moves to the previous heading. K moves to the next link.

Use B for a button, X for a checkbox, C for a choice box, E for a text box, and F for any form control.

Use T for a table, R or A for a radio button, L for a list, and I for a list item.

Use D for a landmark, G for a picture, P for a paragraph, and S for a list box.

A landmark is a named page area, such as main content or navigation. A radio button chooses one option from a group.

Numbers 1 through 6 find headings at that level. Hold Shift with any quick key to move backward.

Voice examples are "Next heading", "Previous link", "Next form control", and "Next heading level two".

These keys move through the page. They do not type letters until you enter a text box for editing.

11.5 Open links and use lists

Move to a link or button, then press Enter. Say "Open current link" or "Activate current element" for the same task.

Say "Find login" or "Find contact us" to look for a matching item. Listen to the choice before you accept it.

F7 or Insert+F7 opens a link list. F6 or Insert+F6 opens a heading list.

You can also say "List links", "List headings", or "List fields".

Use arrows, Home, End, and Enter to choose. Escape or "Close list" returns to the page.

A heading choice moves your reading place. A link choice opens its address.

11.6 Enter or change a web answer

  1. Use Tab to reach the next control, or E to find a text box.
  2. If you found a text box with E, press Enter or say "Edit current field" to start editing.
  3. Type or speak the answer.
  4. Press Enter to save a single-line answer. Use Control+Enter for a box with several lines.
  5. Press Escape to cancel editing and return to page reading.

Tab saves and moves to the next control. Shift+Tab moves backward. Letters now type text while you are editing.

Voice: "Save field" keeps your entry. "Cancel field editing" leaves its earlier value unchanged.

"Select all", "Read selection", and "Scratch" can review or remove text in the active box.

For a checkbox, press Space or say "Check checkbox", "Uncheck checkbox", or "Toggle checkbox".

In a choice box, arrows change the choice. Home and End choose the first and last options.

You can say "Next option", "Previous option", "First option", "Last option", or "Select option" followed by its name.

Read-only boxes cannot be changed. Passwords are hidden in the page text and spoken review.

11.7 Fill in and review a form by voice

Say "Fill out this form". Companion asks for one answer at a time.

Speak the answer to a text question. Use the option name for a choice. Use Yes or No for a checkbox.

Say "Skip" to leave an answer alone. Say "Cancel form" to stop the guided questions.

Some forms reveal more questions after an answer. Companion checks for them as you go.

Say "Review form" to hear the answers. Say "Review and submit form" to start the review before sending.

Say "Continue review" to hear the next part. If an answer is wrong, say "Change this field" or name the field.

You can also say "Change field two". Give the new answer, then review again.

Say "Yes" only when all answers and the named button are right. "No" stops the submission.

Changing an answer after review cancels the older Yes or No request. Review again before submitting.

Keyboard: Enter or Space on a web Send or Submit button uses that website's own checks. It does not start the voice review.

File uploads, some custom controls, and human-verification checks may need help. If a page cannot be read, do not guess at a final button.

Say "Ask for help" to hear which page needs attention.

11.8 Read a web table and leave a page

Move to a table with T or "Next table".

Control+Alt+Up Arrow and Control+Alt+Down Arrow move through rows. Control+Alt+Left Arrow and Control+Alt+Right Arrow move through columns.

Control+Alt+Home and Control+Alt+End reach the first and last columns. Control+Alt+Page Up and Control+Alt+Page Down reach the first and last rows.

Voice choices include "Next row", "Previous column", "First row", "Last row", "First column", and "Last column".

Companion reads the cell text, its heading, and its row and column when available.

Alt+Left Arrow goes back to the previous page. Alt+Right Arrow goes forward. "Go back" and "Go forward" do the same.

F5 or "Refresh page" reloads the page. Alt+T lets you type an app command.

Escape from ordinary page reading opens the web browser menu. If a text box, page dialog, or item list is open, Escape closes that first.

"Leave website" also opens the web browser menu. "Close browser" or "Main menu" leaves the browser activity.

12. Bookmarks And Web History

12.1 Save the current page

A bookmark saves a page address so you can open it later. Older website favorites appear in the same saved list.

  1. Open the page you want to save.
  2. Say "New bookmark". You can also choose it from the web browser menu.
  3. Say a short name, or type the name and press Enter.
  4. Listen for the saved name.

A name can have up to 60 characters. Choose a new name if the one you gave is already used.

"Save favorite as News" remains available as a voice shortcut.

12.2 Open or find a bookmark

Choose Go to bookmark. Use arrows and Enter to choose the saved page.

Press the first letter of a name to move among matching names. Type several letters promptly to choose a closer match.

For example, type n then p to find a name that starts with np. Pause before starting a different name.

You can also say enough of the name to identify it. If two names match, say more or use the arrows.

"Open favorite News" opens that saved name directly. "List bookmarks" opens the bookmark list.

Home and End reach the first and last items. An empty list says it is empty. Escape returns to the web browser menu.

If your chosen browser cannot start, Companion tries the included Firefox browser. Your browser choice stays saved. Your bookmarks stay saved too.

If a page cannot open, you stay in the web browser menu. Check internet access, then try the bookmark again.

12.3 Rename or delete a bookmark

Choose Rename bookmark, then select a name with arrows and Enter. Say the new name, or type it and press Enter.

Choose Delete bookmark, then select a name with arrows and Enter. That removes the saved bookmark.

Deleting a bookmark does not delete the website or its contents. Escape cancels naming or closes the list.

Use first-letter or several-letter search in both lists, just as you do when opening a bookmark.

12.4 Open a page from history

Web history is a saved list of recent secure page addresses. It keeps up to 200 entries, newest first.

  1. Choose Web history in the web browser menu.
  2. Use arrows to hear page names, or type letters to find a name.
  3. Press Enter to open the page.

History stays saved when you close and reopen Companion. Back and Forward use the pages in the currently open browser session.

12.5 Resume where you left off

Open Options, then Web browser options. Check Keep browser window open if you want to keep a page for later.

With it on, Escape from page reading opens the web browser menu and leaves the page open.

Choose Resume where you left off to return to that page and your reading place.

With it off, leaving page reading closes Companion's browser windows. The Resume choice is then absent.

If a retained page has been closed elsewhere, Companion removes Resume and keeps the menu usable.

Bookmarks and history remain saved with either setting.

18. Change Your Options

18.1 Open, change, and save a setting

Say "Options" or press Alt+O. The app opens the Options menu.

  1. Use arrows to choose a category, then press Enter.
  2. Use Tab or Shift+Tab to reach a setting, OK, or Cancel.
  3. Use arrows to change a listed choice. Press Space to check or uncheck a box.
  4. Type in a text box when needed.
  5. Choose OK to save your changes. Choose Cancel or press Escape to leave them unchanged.

By voice, use "Next", "Previous", and "Okay" to open a category. Say the setting name and its value when supported.

Say "Cancel" or "Back" to return to categories without saving. Say "Close settings" to leave Options.

Opening another category or tool before choosing OK discards unsaved setting changes.

18.2 Choose how much speech you hear

Verbosity options controls how many hints the app reads. High gives full hints. Medium gives shorter hints. Low gives brief prompts.

These choices do not shorten a document, email, error message, or Yes or No question.

Spoken punctuation controls which marks are read. Choices are none, some, most, and all.

Typing echo controls what you hear while typing. Choose words, characters, characters and words, or none.

Delayed phonetic pronunciation adds a letter's spoken name after a short pause. For example, B is followed by Bravo.

It is on by default. Choose a delay of 0.5, 1, or 2 seconds, or turn it off.

Voice examples are "Verbosity medium", "Punctuation most", "Typing echo words", "Phonetics off", and "Phonetic delay 1 second".

Moving again or stopping speech cancels a letter hint that has not yet been read.

18.3 Voice and Synthesizer options

Listen to the voice sample before saving rate, volume, or pitch. Control silences the sample. Escape cancels the category.

The checkbox Allow narration text to be sent to OpenAI controls consent for online speech. A blank key box keeps the saved key.

Remove saved AI key removes that setup when you save. Ask your helper if you need to set up an AI voice.

18.4 Input and Email options

Input options chooses Normal, Commands only, or Dictation only. The choice affects how spoken words are used.

Email options chooses plain text or HTML. HTML keeps formatting such as bold text and links.

Sending account chooses the address used for new mail. Messages per list sets how many summaries load at once.

18.6 Web browser options

Default search engine chooses Google, Bing, Brave Search, or DuckDuckGo.

21. Find Your Guide Files

22. Fix A Problem

22.1 Companion hears the wrong words

Speak one short sentence or command at a time. Wait for the reply before speaking again.

Check the microphone choice and its position. Try a headset so the app is less likely to hear its own speech.

Use "Commands only" while reviewing text. Switch to "Normal mode" before writing by voice.

If a command still fails, press Alt+T, type it, and press Enter. Read the result before trying again.

Do not repeat a send, move, or delete if the result was uncertain. Check what happened first.

22.2 You cannot hear speech

Check the computer's sound output and volume. Press Control to clear old speech, then give a new reading command.

Try "Use SAPI" if an AI voice is unavailable. AI speech needs an internet connection and a working service setup.

Use Voice options to check Speech volume and Speech rate. Ask your helper if no voice can be heard.

22.3 Email or a website will not work

For mail, check the selected account with "Which email account?". Ask your helper to check sign-in if needed.

For a page, try "Refresh page" or F5. Use "List links" if its layout is hard to explore.

If quick keys type letters, press Escape to leave text editing. Use the Companion page window for its reading keys.

A site may ask for human verification or use a control Companion cannot read. Ask for help rather than guessing.

Some email folder changes and forwarded attachments are limited by the service or this version. Review the related chapters before trying again.

22.4 A guide or update will not open

Close any open guide files, then say "Open user guides" again. This asks Companion to refresh its guide copies.

If your Documents folder is not available, ask your helper to restore access to it.

For a failed update, keep using the current app if it opens. Try Check for updates again later.

Use the installed desktop icon. If it opens an older version, ask your helper to check the installation.

Tell your helper the app version, what you tried, and the exact error message. This makes the problem easier to find.
